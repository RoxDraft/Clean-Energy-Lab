# Energy Anatomy · กายวิภาคเซลล์พลังงาน

Interactive simulation แสดงโครงสร้างชั้นวัสดุและการจัดเรียงอะตอมของโซลาร์เซลล์และแบตเตอรี่ ในสไตล์แอป anatomy ที่แบ่งเป็น "ระบบ" ทำงานร่วมกัน

> 🤖 **สร้างโดย Claude (Anthropic)** — ออกแบบ เขียนโค้ด และเรียบเรียงเนื้อหาโดย Claude เมื่อ ต.ค. 2026 ตามคำขอของเจ้าของ repo

## เปิดใช้งาน
เปิด `index.html` ในเบราว์เซอร์ได้ทันที (ไฟล์เดียว ทำงาน offline) หรือเปิดผ่าน GitHub Pages

## เนื้อหา
- **โซลาร์เซลล์ 6 ชนิด:** PERC · TOPCon · HJT · Back-contact · CdTe · Perovskite–Si Tandem
- **แบตเตอรี่ 5 ชนิด:** LFP · NMC · Sodium-ion · Vanadium Flow · Lead-acid
- **มุมมองชั้นวัสดุ:** แยกชั้นแบบ exploded แบ่งตามระบบ ซ่อนหรือแสดงได้ทีละระบบหรือทีละชั้น และคลิกดูวัสดุกับหน้าที่ของแต่ละชั้น
- **มุมมองระดับอะตอม:** โครงผลึกแบบ 3D หมุนได้
  - โซลาร์: โฟตอนสร้างคู่ e⁻/h⁺
  - แบตเตอรี่: ion เคลื่อนที่ระหว่างขั้วเมื่อชาร์จหรือคายประจุ พร้อมแสดง SOC

## ข้อจำกัด
- เป็นแบบจำลองอย่างง่ายเพื่อการเรียนรู้ ความหนาของชั้นและระยะห่างอะตอม**ไม่ตามสเกลจริง**
- โครงผลึก LFP และ Prussian blue เป็นแบบย่อ ไม่ใช่ผลึกศาสตร์ที่แม่นยำ
- ตัวเลขที่มีเครื่องหมาย ◇ คือข้อมูลพื้นฐานที่ยังไม่ได้ตรวจกับแหล่งต้นฉบับ
- ตัวเลขตลาดอ้างอิง BNEF 2025, ITRPV/CPIA via TaiyangNews, pv magazine และ ESS News (2026)
